# Saffron & Slate ERP

A Flutter restaurant management app for taking and managing orders, running the kitchen display, managing tables, menu, inventory, and staff payouts — with dashboard and sales reports.

## Features

- Executive dashboard with sales, P&L, and KPI charts
- POS / order management
- Kitchen display system (KDS)
- Table management and bookings
- Menu management
- Inventory tracking
- Staff payouts
- Reports (sales, income/expense)

## Tech

Flutter, Dart, Provider for state management, fl_chart, google_fonts, intl, uuid. Local, offline-first data.

## Getting started

```sh
flutter pub get
flutter run
```
